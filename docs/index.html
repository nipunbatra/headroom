What can I clear?

Old files and installers
Filter large files by size, kind, and modification date. Open a Quick Look preview or reveal the original in Finder.
Builds and caches
Find idle projects, inspect individual models and build folders, and choose which cleanup rules Quick Cleanup includes.
Apps and their data
Uninstall a bundle and keep its settings. Add individual support files during review when you want those removed too.
Duplicate files
Review copies side by side in a group. Headroom compares the contents again before removing a copy.

Install Headroom

Version 0.4.0 for macOS Sonoma and later.

  1. Download the ZIP and open it in Finder.
  2. Drag Headroom into Applications, then open it to start a read-only scan.

The download is Developer ID signed. This version is distributed without Apple notarization. See the release notes for the checksum and Gatekeeper details.
